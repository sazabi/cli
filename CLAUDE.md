# Sazabi CLI

The command-line interface for [Sazabi](https://sazabi.ai).

## About

This is a release mirror. The CLI is developed in the private Sazabi monorepo; each release lands here as the exact content published to npm as [`@sazabi/cli`](https://www.npmjs.com/package/@sazabi/cli). Do not commit directly — content flows here via automated release workflows and direct commits will be overwritten on the next release.
